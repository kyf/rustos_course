# 课程导读

欢迎来到 RustOS。

这套教程的目标不是简单地拼装一个能启动的内核，而是逐步理解：CPU 如何开始执行代码、Bootloader 如何把控制权交给内核、虚拟地址如何被翻译成物理地址、页表如何组织、进程如何拥有彼此隔离的地址空间，以及操作系统如何在这些机制之上实现调度和系统调用。

## 学习目标

1. 理解操作系统、硬件、应用程序之间的职责边界。
2. 阅读 x86_64 的基本执行状态，包括 RIP、RSP、控制寄存器和页表。
3. 理解 BIOS/UEFI、Bootloader、ELF 与内核入口之间的关系。
4. 独立解释虚拟地址、物理地址、页表、页帧、TLB 的作用。
5. 实现物理页帧分配、虚拟地址分配和映射管理。
6. 建立独立地址空间，为进程隔离、用户态和系统调用打基础。

## 前置知识

熟悉 Rust 基础语法、所有权、借用和生命周期；能阅读泛型、trait 与错误处理代码。本课程会在需要时解释 `unsafe`、裸指针、内联汇编和 `no_std`，但不重新讲解 Rust 语法基础。

## 如何阅读

每课包含目标、原理、实现视角、验证方式和练习。代码片段若标注为“示意”，就不是可直接复制运行的完整内核实现；真实实现必须结合项目当前 crate 版本、内存布局和启动配置。
